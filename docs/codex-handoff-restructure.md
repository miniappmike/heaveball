# Handoff for Codex: repository restructure

**Date:** 2026-11-23 · **From:** Claude · **Branch:** `claude/modest-bardeen-e1p87k`, merged into `main`

The repository layout and the Matchroom build changed. Read this before your next Matchroom change, and start from the latest `main`.

## What moved

| Before | Now |
|---|---|
| `matchroom/dist/match-<hash>.js` | `matchroom/src/match.js` (stable name, edit this) |
| `matchroom/dist/view-<hash>.js` | `matchroom/src/view.js` (edit this) |
| `matchroom/dist/index.html` (hand-edited) | `matchroom/src/index.html` (edit this) |
| `matchroom/build.py` | `matchroom/tools/build.py` |
| `matchroom/fields/*.jpg`, `matchroom/dist/fields/*.jpg` | `matchroom/assets/fields/*.webp` |
| `matchroom/dist/dirt.png`, `fields/templates.js` | Removed (unused) |
| `matchroom/dist/summary.docx` | Removed; the build no longer needs Pandoc |
| Root `summary.md`, `summary.docx` | Removed (stale copies of `matchroom/summary.md`) |
| Root PDFs, `Heaveball_*.md`, history, `Inspiration` | `docs/` (`Inspiration` is now `docs/Inspiration.md`) |
| Root `*reference.png` | `docs/references/*.webp` |

`matchroom/dist/` is now generated output only. Never edit it by hand.

## How to make a Matchroom change

1. Edit `matchroom/src/` (and `matchroom/assets/` for textures).
2. Run `python3 matchroom/tools/build.py`. It needs only Python 3.
3. Commit `src/`, `assets/` and the regenerated `dist/` together.
4. Update `matchroom/summary.md`.
5. Open a pull request into `main`.

Preview locally with `python3 -m http.server 8000 --directory matchroom/dist`. Use a server, not `file://`: the field textures load as separate files.

## What the build produces

- `dist/index.html`: the page with `match.js` and `view.js` inlined as one script, and the default field (`park-red`) embedded as a data URI. There are no separate `match-*.js` / `view-*.js` files any more, and no filename hashing.
- `dist/fields/*.webp`: the other field textures, loaded the first time a viewer picks that field.
- `dist/summary.md`: `matchroom/summary.md` plus a build record. `matchroom/summary.md` itself no longer has a build record section.

The build is deterministic: running it twice gives the same `index.html`.

## CI check on deploy

`.github/workflows/pages.yml` now runs on any change under `matchroom/`. Before deploying, it rebuilds `dist/` and fails if the result differs from the committed `dist/` (ignoring `dist/summary.md`, which has a timestamp). If you edit `src/` without rebuilding, or edit `dist/` by hand, the deploy stops.

## Field textures and markings

- Textures are 2000×1360 WebP, generated by `matchroom/tools/generate_fields.py` (needs `numpy` and `Pillow`). It samples colors from the original artwork in `matchroom/tools/field-palettes/`. Its seeds are fixed, so re-running it gives the same images.
- Field lines, the ring, quadrant spots and runway marks are **not** in the textures. `drawFieldLines()` in `view.js` draws them as vector paths, so they stay sharp at any size.
- The all-weather fields carry the turf stripe pattern across the no-possession dirt strips.

## Other behavior changed in the same branch

These are documented in `matchroom/summary.md` ("Calls and stoppages", "Penalties"):

- **Pauses.**
  - Scores, penalties, turnovers and stoppages freeze play in place for 3.5 s.
  - A tackle that keeps possession pauses 2 s, with no popup.
  - The tackled player wears a black inner ring until the next possession.
  - Reset-type tackles (free run lane, center catch stopped short, runway turnover) hold the spot through the pause via `delayedRestart`.
- **Call popups.** They are drawn in the middle of the field by `drawCallout()` in `view.js`. The engine raises them with `call(text, sub)` in `match.js`.
  - CENTER!: 2-, 3- and 5-point scores.
  - TAKEAWAY!: 1-point center-zone interceptions and fumble recoveries.
  - TURNOVER.
  - PENALTY: the penalized player is highlighted red.
  - OUT OF BOUNDS: only when the same team keeps the ball. A possession change out of bounds is a TURNOVER.
  - The popup clock stops while paused.
- **Penalties.**
  - Every penalty awards a free run lane, through the shared `penalize(p, why)` helper.
  - New penalties: a Runner or Heaver crossing past their own half, and a carrier holding the ball in the no-possession zone.
  - Low IQ and Discipline raise the odds.
  - Tuning constants are `LAPSE`, `DIRT_SLIP`, `RING_CLEAR` and `BACK_BLOCK` near the top of `match.js`.
- **Freeze fix.** `s.ball()` returns the last known ball position during restart pauses. Before this, a missing ball crashed drawing and froze the field. `frame()` also catches drawing errors so the animation loop never stops.
- **Idle redraw skip.** `frame()` redraws only while playing or when something visible changed (paused, halftime screen, pregame).
