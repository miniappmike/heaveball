# Heaveball

Heaveball is a fictional eight-a-side sport centered on a shared scoring ring. This repository contains the rules, coaching material, player-generation specifications, visual references, and the browser Matchroom simulation.

## Matchroom source

The complete source for the live [Heaveball Matchroom](https://heaveball-matchroom.hardyburl128.chatgpt.site/) is available in [`matchroom/`](matchroom/README.md). It includes the simulation engine, renderer, static interface, field texture, build script, deployment manifest, and generated contributor guides.

The Matchroom is intentionally buildless at runtime: the deployed game is ordinary HTML and JavaScript, so its gameplay logic can be read directly in the repository.
